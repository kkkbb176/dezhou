## 4. 全下 51.1% / 48.9% 的来源

全下尺寸 `100BB`：

- 到达范围：239 个死牌过滤后的可行动组合；
- 价格：`9750 / 20050 = 48.63%`；
- 继续门槛：`48.63% + 19% = 67.63%`；
- 低于门槛的组合弃牌；达到门槛的组合进入跟注桶；
- 跟注桶：43 个组合；
- 弃牌概率：51.12%；
- 跟注概率：48.88%；
- 再加注概率：0%（Hero 已全下，对手不能再加注）。

对手面对全下的跟注条件**不是**开池范围直接拿来算权益，而是：

1. 从求解器 UTG 开池到达范围出发；
2. 按全下尺寸的价格和门槛筛出会继续跟注的组合；
3. 对筛出的跟注桶重新归一化；
4. 用该条件范围计算 Hero 的权益；
5. 全下跟注桶权益为 **79.41%**（生产页面为 80.1%）。

因此“51.1% / 48.9%”是当前结构性响应模型对全下尺寸的输出，不是从某个真实统计样本直接观测到的频率。

## 5. 常规尺寸的 35.5% 再加注概率

- 该 35.5% 是**总概率**（无条件概率），不是「继续后条件概率」。
- 在 4BB 尺寸下，条件再加注率约为 `35.5% / (1 - 0.7%) = 35.76%`。
- 在 12BB 尺寸下，条件再加注率约为 `35.5% / (1 - 44.0%) = 63.4%`。
- 这说明常规尺寸下，对手越少弃牌，进入再加注分支的条件概率越高；这不是重复计票，概率总和仍为 1。

## 11. 最终回答

1. **高额全下 EV 是否存在计算错误？**
   没有发现确定性算术错误。资金流、条件范围、概率归一化和 EV 与独立复算一致。

2. **如果没有，哪些假设让它胜出？**
   主要是 UTG 面对全下的跟注率 48.9%、跟注条件范围权益约 79-80%、全下没有再加注分支，以及常规尺寸再加注分支未展开 Hero 5Bet 且非全下使用摊牌终止近似。当前响应频率是结构性先验，不是统计校准值。

3. **常规加注后的再加注分支有没有被公平计算？**
   没有完全公平。它没有重复扣款、没有漏账，但只展开 Hero 的 FOLD / CALL，没有展开 Hero 的 5Bet 反推全下，因此会系统性低估常规加注面对再加注时的价值。

4. **当前推荐能信到什么程度？**
   可以把它当作“当前模型下的最高 EV 建议”，不能当作“GTO 已证明 AA 必须全下”。要提升可信度，下一步需要补上 Hero 5Bet 分支，并用真实或经校准的对手响应频率替换结构性先验。当前基线可用于继续开发，但不应据此宣称盈利能力。
