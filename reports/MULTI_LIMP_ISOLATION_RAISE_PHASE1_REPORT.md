# MULTI_LIMP ISOLATION RAISE PHASE 1 — REPORT

固定节点（使用者指定）：

```text
6-max｜盲注 1/2｜Hero BTN K♠Q♠｜UTG / HJ / CO 全部 limp 2 筹码（1BB）
底池 9 筹码（4.5BB）｜Hero 需补 2｜身后 SB(95BB) / BB(110BB) 未行动
筹码：UTG 90 / HJ 120 / CO 130 / BTN 150 / SB 95 / BB 110（BB 单位）
```

本轮**只**做这个节点的三段修复，**不动**任何既有阈值去凑结果。

## A. 根因：三个缺陷，逐个给证据

### A1｜`CLEAR_CALL` 没有作用域 —— 它只证明了「跟注 > 弃牌」

修复前，面对下注的分支里只给两个动作算了证据：

| 动作 | 修复前的证据 | 说明 |
|---|---|---|
| FOLD | `EXACT`，EV ≡ 0 | 节点增量口径的定义 |
| CALL | `PROXY_EV`，EV = +2.05 筹码 | 只与弃牌比过 |
| RAISE | `HEURISTIC`，**EV = null** | 没有模型 ⇒ 无法参与比较 |

而 `chooseByEvidencePriority` 的规则是「**边际清晰** ⇒ 低质量证据不得覆盖」。
于是 **CALL 的 `CLEAR_CALL` 被当成「CALL 优于一切」**，加注连被算一次 EV 的机会都没有：

```text
修复前实测（同一节点）：
  决策边际 = CLEAR_CALL（EV 2.00 vs 容差带 ±0.55）
  RAISE 6.0BB —— heuristicScore 0.78
  overrideBlockedReason = CANNOT_OVERRIDE_CLEAR_SUPPORTED_CALL
```

**根因不是阈值，而是缺少作用域**：一个只比较过「跟注 vs 弃牌」的结论，
被赋予了拦截「其他所有动作」的权力；而加注这边**根本没有 EV 可比**。

### A2｜隔离加注没有独立证据 —— 只有「牌力够大就加注」的启发式

修复前的加注依据是 `shouldRaise(equity, requiredEquity, tier, …)`：
一个**不含对手响应**的量级判断。它无法回答：

- 三个跛入者里会有几家跟注？（弃牌率）
- 加注到多大才既能收死钱又不把所有人打跑？（尺寸）
- 被跟注时我的权益是多少？（**对跟注范围**，不是对到达范围）
- 身后 SB/BB 的 squeeze / cold-3bet 风险值多少？

### A3｜三个跛入者都是 **1225 组合的任意两张**

`buildBaseRange` 对「无人加注的被动进入」一律使用 `bigBlindCheckWeights()`：

```text
修复前实测：枪口位｜组合 1225｜熵 10.22｜来源 HEURISTIC｜可信度 0.30
            劫持位｜组合 1225｜熵 10.22
            关煞位｜组合 1225｜熵 10.22
```

三个位置、三种类型（松弱 / 普通偏被动 / 跟注站）拿到的是**完全相同**的范围 ⇒
画像、位置、类型**全部进不去**范围链路，Hero 权益永远是一个与对手类型无关的数。
这与上一轮修掉的 P0 缺陷（画像只在决策末端当偏好修正）是同一类错误的翻前版本。

## C. 修复后的判定链（同一节点）

```text
FOLD  : EXACT  EV ≡ 0
CALL  : PROXY_EV  EV = +2.00 筹码          （作用域 VS_FOLD_ONLY）
RAISE : INDEPENDENT_STRATEGIC_EVIDENCE     EV = +4.00 筹码（隔离模型）
        ↑ 同一零点（弃牌 ≡ 0）、同一容差带 ±0.55 ⇒ **正面比 EV**
```

实测输出（`scripts/review-hand-07.ts`，主对手 UTG 松弱）：

```text
建议：RAISE｜尺寸 8BB（16 筹码）｜置信度 0.30（MEDIUM_LOW）｜分类 MARGINAL
决策边际：CLEAR_CALL_OVER_FOLD｜EV 2.00 vs 容差带 ±0.55    ← 名字已如实
[ISO_RAISE_MODEL_EV] 隔离加注（加注到 8.0BB）：… EV_iso = 4.00 筹码
      ｜对 limp-call 条件范围权益 56.8%（对到达范围权益 36.4%，**不用于**证明加注）
      ；代理 EV = 4.00 筹码 vs 跟注 2.00 筹码 ⇒ 依据来源 = INDEPENDENT_STRATEGIC_EVIDENCE
动作来源：INDEPENDENT_STRATEGIC_EVIDENCE｜范围 RAISE_INDEPENDENT_MODEL
备选：FOLD（EXACT）｜CALL（PROXY_EV）
```

三条必须同时成立的纪律，实测都成立：

1. **不是**「CLEAR 被删掉」：`CLEAR_CALL_OVER_FOLD` 仍然存在、仍然清晰，
   只是它的作用域写明 `CROSS_ACTION`（加注带着自己的 EV 参与了比较）。
   没有第二个动作带 EV 时，作用域如实回落到 `VS_FOLD_ONLY`（T8 锁定）。
2. **不是**「加注启发式升级」：加注的启发式分（0.78）没有参与胜负，
   决定胜负的是两个**代理 EV**；`MATH_DOMINANCE` 的措辞也跟着变成
   「本节点的加注**有**自带的代理 EV 并参与了比较」。
3. **不是**「硬编码 KQs 加注」：M7 变异（只在 K♠Q♠ 时给加注 EV）**被 T1/T4 抓住**。

## D. limp 到达范围（§4）

```text
到达范围 = 既有「无人加注宽范围」基线 × 有效宽度^(档位/5)
有效宽度 = 原型宽度 与 人群先验(0.68) 按**画像可信度**混合 + 位置修正×可信度
```

实测（3 家 limp，每人补 14 筹码 ⇒ 需要 35.9% 权益）：

| 座位 | 原型（可信度） | 到达宽度 | 弃 / 跟 / 再加 |
|---|---|---|---|
| 关煞位 | 跟注站（0.35） | 0.76 | 52.3% / 44.7% / 3.0% |
| 枪口位 | 松弱（0.35） | 0.71 | 54.6% / 42.4% / 3.1% |
| 枪口位 | 普通（0.35，UNKNOWN→NORMAL） | 0.61 | 59.2% / 37.1% / 3.7% |
| 劫持位 | 无画像 ⇒ 人群先验 | 0.68 | 58.4% / 38.2% / 3.4% |

**范围本身也进了引擎主链**：这三个座位的对手范围现在是**逐家不同**的
（修复前全是 1225 组合 / 熵 10.22），因此 Hero 权益随画像变化：

```text
T2 实测：跟注站 36.56% ≠ 紧手 36.27%（同一个种子、同一批对手）
```

## E. 联合响应与隔离 EV（§5–§8）

### E1 响应模型（唯一实现，两个调用方共用）

```text
price      = 他要补的筹码 / (隔离后底池 + 他要补的筹码)
strength   = 1 − tier/5
继续比例    = clamp((strength − price×fold/call) / (1/5) + 0.5, 0, 1)   ← 连续混频
概率        = 按**人群形状**对「跟注类集合 / 弃牌类集合」计权
再加注      = 仅 tier ≤ 1，权重 min(0.85, 0.35×reraise)（不是全有全无）
```

🔴 两处**必要的建模决定**（都不是调参，都写进了代码注释）：

1. **连续混频**：`strength` 只有 6 档，硬切会让「跟注站 vs 松弱」落到同一档集合，
   两者的弃牌率**完全相同** ⇒ 画像形同没接进来。按档位步长 `1/5` 做线性混频后方向恢复。
2. **概率按人群形状计权**：到达范围是 `基线 × 宽度^(档位/5)`，越宽的玩家弱档占比越高。
   若直接用它算弃牌率会得到**反向伪相关**（实测：跟注站弃牌 55.8% 反而高于人群 54.3%）。
   宽度决定**他用什么牌进池**，倾向决定**他怎么应对加注** —— 因此概率按同一牌面结构
   下的人群形状计权，而**条件范围仍然按他自己的到达范围切**。

方向自检（T2 锁定）：跟注站弃牌 52.3% < 松弱 54.6% < 紧手（更高）；再加注倾向高的原型更高（T6）。

### E2 联合响应（条件独立近似）

```text
3 家 limp（≥2 家可跟注）｜全弃 17.8%｜1 家 43.2%｜2 家 29.2%｜3 家 6.5%
任一再加注 9.5%｜期望跟注人数 1.21
⚠️ HEURISTIC_INDEPENDENCE_ASSUMPTION：未建模响应相关性（真实牌局里正相关）
```

### E3 隔离 EV（零点 = 弃牌 0，单位筹码）

```text
EV_iso = P(全弃)×底池
       + Σ_k P(k 家跟) × [eq_k × (底池 + R + k×Δ) − R]
       + P(任一再加注) × (−R)            ← 被再加注按不再继续处理
       − cold3bet 风险 × R
其中 Δ = R − 跟注者本街已投入（跛入者的 1BB **已经在底池里**）
```

🔴 本轮修掉的一个**虚增**：第一版按 `2R + (k−1)R` 计（等于把跟注者已投入算两遍），
实测该节点被虚增 ~1.2–1.8 筹码（4.46 → 修正后 4.21）。修正项写进了 `assumptionsZh`。

条件范围权益（**独立计算**，禁止用到达范围权益）：

| 口径 | 数值 | 用途 |
|---|---|---|
| 对到达范围（3 家一起） | 36.4% | **只作对照**，不得用于证明加注 |
| 对 1 家跟注条件范围 | 56.8% | 跟注分支 k=1 |
| 对多家跟注条件范围 | 30.2% | 跟注分支 k=3（2 家按线性插值，已声明） |

## F. 画像 / 人数 / 身后玩家的敏感性（都不是只改文案）

### F1 人数 ⇒ 尺寸（无任何硬编码）

| 节点 | 模型请求 | 落到合法网格 | 全弃 | EV_iso | 身后修正 |
|---|---|---|---|---|---|
| 1 家 limp（UTG limp，HJ/CO 弃） | 5.04BB | 5.00BB | 58.1% | +3.03 | −0.68 |
| 2 家 limp（UTG/HJ） | 6.05BB | 6.00BB | 33.0% | +3.80 | −0.82 |
| 3 家 limp（UTG/HJ/CO） | 7.06BB | 8.00BB | 20.2% | +3.74 | −1.09 |

尺寸公式（公开、可测）：`3BB + 1BB×人数 + 位置(BTN +0.5/CO +0.25/前位 −0.25) + 黏度 + 筹码深度`，
再**对齐合法尺寸网格**（`closestSizeTo`，与决策层共用同一条规则）。
请求 7.06BB 而网格只到 6/8BB ⇒ 取 8BB，并且**用 8BB 重算 EV** ——
不允许拿「7.1BB 的 EV」去证明「8BB 的加注」。

| 主对手画像 | CO 到达宽度 | CO 弃/跟 | EV_iso | 跟注 EV | 结论 |
|---|---|---|---|---|---|
| 跟注站 CALLING_STATION | 0.76 | 52.3% / 44.7% | +4.21 | +2.02 | RAISE |

## 诚实声明（本轮**没有**做到的事）

1. **RAKE = NOT_IMPLEMENTED**：所有 EV（含 CALL 的代理 EV）都未计抽水，本项目无 Rake Engine。
2. **响应独立性是假设**：`HEURISTIC_INDEPENDENCE_ASSUMPTION`，真实牌局里多家响应正相关。
3. **多人权益只有 1 家 / 3 家两个实测点**，2 家按线性插值（HEURISTIC）。
4. **画像输入限制**：手动录入只支持**一个** `quickProfile`，因此多人桌上只有
   一个座位能带原型（其余按人群先验 + 位置修正）。这是**输入层**限制，不是模型限制；
   `contextBuilder` 的 `limpProfileFor` 已经按座位取值，多画像录入一旦支持即可直接用。
5. **Hero 在 BB 的「过牌 / 加注」节点没有隔离事实包**（跟注代价 = 0，
   不是「面对跛入要跟注」的节点）—— 未建模，不伪造。
6. **到达范围不是实测频率**：它是既有基线按档位衰减的形状，不是数据库统计。
7. **翻前 provider 乘数通道仍然不生效**（`是否改变范围 false` 那一行的来源）：
   本轮新增的「跛入原型通道」是**另一条**路径，已让权益真的变化（Δ +0.12~+0.29 个百分点），
   并且 `画像链路` 行现在**并报两条通道**，不再用单通道的 false 冒充「画像没进范围」。
