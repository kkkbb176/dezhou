## 五、范围转换与含义核对

### 5.1 原始输出 → 牌名映射

- 解析器读取 `range.hands`，按 `hand.hand` 的牌名对齐，例如 `AA`、`AJo`、`72o`。
- 不按数组序号灌入。
- 169 个牌型类全部存在，且每类保留原始组合数（对子 6、同花 4、不同花 12）。

### 5.2 原始数值含义

本节点的载荷包含行动频率：

- `FOLD`
- `RAISE 2.5`
- **本节点实际不存在 `ALL_IN` 动作**（已用缓存文件逐条核对：动作变体只有 `FOLD` 与 `RAISE 2.5` 两种，跨 169 类求和 `ALL_IN = 0`）
- 范围提取口径是 `RAISE + ALL_IN` 频率之和（对更一般的场景保留 ALL_IN 通道），再夹到 `[0,1]`；在本节点上等价于只取 `RAISE 2.5` 的频率

因此这里得到的是**某个手牌类采取加注动作的频率**，不是已经条件化好的最终范围权重。后续必须结合到达该节点的范围与死牌过滤，再归一化。不能把同一份先验或行动似然重复乘第二次。

### 5.3 关键统计量

实测：

```text
牌型类数              = 169
正权重牌型类数        = 169
总组合数（未去死牌）  = 1326
类别频率之和          = 19.1157959827
按类别组合数加权总量  = 121.093845
死牌过滤后的组合宇宙  = 1225 = C(50,2)
正权重组合数          = 1225
有效组合数 1/Σp²      = 94.05598276264851
归一化熵              = 0.6564907113362348
```

解释：

- **1225 是正权重组合数，也是去掉 Hero 底牌后的全部组合宇宙**；由于求解器在 169 类上都保留了非零 RAISE 频率，正权重组合数必然等于全部合法组合。
- **1225 不携带范围宽窄信息**，不能称为“有效组合数”。
- 真正的等效宽度是 `94.1` 个组合。
- 加权组合量 `121.093845`，与等效宽度不同是正常的：前者按类组合数加权，后者对高权重大小敏感。

### 5.4 死牌过滤与归一化

- Hero 底牌为 `A♥ A♦`。
- 组合宇宙从 1326 中移除所有包含这两张牌的组合，得到 1225。
- 过滤后重新归一化，`Σp=1`。
- 生产侧 `rangeProvenance` 实际消费的正是这份范围，不是重新构造的另一份。
