### 0.3 Alpha 阶段**自测**发现的真实 Bug（2 CRITICAL + 9 MAJOR/MINOR）

| # | 缺陷 | 后果 | 修正 |
|---|---|---|---|
| **A1** | `rebuildPendingQueue`：行动者弃牌后 `findIndex` 返回 -1，`Math.max(0,-1)` 把 `order[0]` 转到队尾 | UTG 弃牌后队列 `[CO,BTN,SB,BB,HJ]`（HJ 被挪到末尾）→ **合法输入被拒，端到端完全跑不通** | 在**含弃牌者**的完整顺序里定位，再从他之后环绕 |
| **A2** | 蒙特卡洛**均匀抽样** | Range 贝叶斯后验**完全不参与**权益计算 → **Range → Equity 链形同虚设** | 新增按 CDF 的加权抽样；无权重时与修复前逐位一致 |
| A3 | 似然权重（最大 4.0）被当概率传入 | `validateActionModel` 拒绝 → **每次范围更新静默失败** | 归一化到 `[0,1]` |
| A4 | 范围更新用当前街而非行动所属街 | 跨街更新被拒 → 静默失效 | 用 `ActionRecord.street` |
| A5 | 公共牌建局预填 + 推进又发 | `ISSUE.DUPLICATE_CARD` | 建局不传 board |
| A6 | 「无决策点」仍给建议 | 输出「建议：过牌」而 Hero 并无轮次 | 新增 `DECISION_POINT_NOT_AVAILABLE` |
| A7 | `activeOpponentCount >= 2` 即拒 | **AA/AKo 面对开池被建议弃牌** | 阈值改为 ≥3 |
| A8 | 翻牌前 `handCategory = 0` → WEAK | 翻牌前不主动下注 | 用起手牌档位标签 |
| A9 | 尺寸取最小值 | 顶对下注 **1BB** | 按牌力档选底池比例 |
| A10 | 置信度「0 = 无数据」混淆 | 置信度被拉到 **0.000** | 区分「信息缺失」与「数据不可信」 |
| A11 | `claimedPot ?? 0` | 「没填」被当「填 0」→ 假 POT_MISMATCH | `null` 语义 |

> **方法论**：A1 与 A7 都是**第一次真正跑端到端**才暴露的 ——
> 单元测试全绿时它们是隐藏的。**「能不能跑通」本身是一种独立的测试维度。**

### 0.2 Step 7 红队发现的缺陷（**12 条 CRITICAL/MAJOR**）

#### 第一轮（作者自查，全部是假阴性）

Step 7 的单元测试 **55/55 全绿**时，红队场景 2（Nit 连续 20 手变激进）暴露出系统**完全不报警**。逐层排查发现 5 个叠加缺陷：

| # | 缺陷 | 错误写法 | 后果 | 修正 |
|---|---|---|---|---|
| D1 | 收缩强度取基线样本量 | `k = baseline.effectiveSampleSize` | 20 手窗口被 400+ 手基线压平，VPIP 15%→45% 算出 **0~1 分** | 改为**温和收缩**，只随近期机会数 |
| D2 | 置信度被连乘三次 | 聚合层 × 状态层 × 调整层 | 20 次机会的信号再砍到约 **1/4** | 聚合层与调整层不再乘置信度 |
| D3 | 置信度刻度错位 | `n/(n + MIN_BASELINE_OPPORTUNITIES)` | 远高于判定门槛的样本仍只得 **0.5** | 按机会数线性映射 |
| D4 | 方向判定用绝对阈值 | `\|Δ\| < 0.01 → NONE` | ±1 次计数差被当成真实方向，**虚假方向冲突**提示 | 两比例差的**标准误**检验 |
| D5 | 方向检验样本量取错 | 用 20 手窗口计数估方差 | PFR 20%→5% 被判「无方向」，**漏掉真实冲突** | 改用全部近期事件机会数 |

#### 第二轮（**独立红队判定 FAIL**）

独立审计员用**不同方法**（400 个确定性种子批量统计 / 边界扫描 / 源码死代码检查）
在第一轮修复后**仍然**找出 3 个 CRITICAL：

| # | 缺陷 | 后果 | 修正 |
|---|---|---|---|
| F1 | 组内方向冲突判 `NONE` → 兜底分支**永不可达** | **「开始大量跟注」被读成「更爱弃牌」**、19 分、无 `RANGE_WIDTH` 调整 | 取**主导方向** + `directionContested` |
| F2 | 充分性/置信度由**跨指标机会总数**决定 | 2 手牌 → confidence **0.900** + 满额幅度；**置信度随样本增加而下降** | 改用**每项指标自身**的机会数 |
| F3 | 方向检验与强度用**不同样本量** | 多喂 40 手同水平历史就**翻转判决**；误报率随历史 12%→**51%** | 样本量固定为窗口机会数 |
| F4 | `deviationScore` 无零假设刻度 | 真值 = 基线时均值 **19.8** 分、12% 误报 | 引入 **z 检验门槛**；均值降到 **8.0** |
| F5 | `SIZING` 组无指标映射 | `SIZE_ANOMALY` 死代码；12 个真实指标**不可见** | 补齐 4 个指标 |
| F6 | 上下文事件不校验 playerId/timestamp | **别人的损失抬高本人 Tilt** | 校验 + 记录忽略 |
| F7 | Hint 时间戳被忽略、静默吞掉 | 状态 `TILT_SIGNAL` 而 Tilt 概率 = 0 | 过滤未来 / 同步 Tilt / `stateProvenance` |
| F8 | Fail Closed 失效 | 畸形输入 **TypeError 崩溃** | 逐字段严格校验 |
| F9 | `asOf` 非有限值 | `NaN` → **未来事件全进** | 新增 `INVALID_AS_OF` |
| F10 | 非计算字段非法 → 整条事件作废 | 26 分 → `UNKNOWN` 0 分 | 剥离非法字段、保留机会 |
| F11 | `MAX_SINGLE_EVENT_SHARE` 死常量 | 改它不影响输出 | 真正接线 |
| F12 | 5000 事件 P95 = **31.3ms** 超预算 | 超出 20ms 热路径预算 | 排序前预解析时间戳 → **15.1ms** |

**为什么两轮都没被单元测试抓到**：那些测试只断言「不该报警时别报警」，
没有断言「该报警时必须报警」。
**教训**：红队场景必须**成对**写（正常对照 + 真实异常），

## 12. 阶段验收门槛

任何 Phase 宣布完成前必须同时满足：

| 门槛 | 判据 |
|---|---|
| 类型检查 | `tsc --noEmit` 零错误 |
| **产物 hash** | `npm run manifest:check` 通过（31 个产物与清单逐位一致） |
| 全部测试 | `npm test` 全绿（含新增用例） |
| 回归 | 已有 921 项测试无一失败 |
| 中文规范 | `test/i18n.test.ts` 全绿（新增界面文案必须补断言） |
| 墨菲审查 | 该 Phase 相关风险条目已更新状态并写明验证方式 |
| 红队审查 | 该 Phase 新增输入路径至少 1 条红队用例 |
| **独立红队** | 该 Phase 必须由**独立**子代理审计，且其方法与开发者测试**不同** |
| **每个真实缺陷** | 必须变成永久回归测试（Bug → 最小复现 → 回归测试 → 修复） |
| 版本追踪 | 新增决策路径已记录 `VersionStamp` |

> **任何核心测试失败，不得宣布该 Phase 完成。**
>
> **禁止通过放宽或删除断言来让测试变绿。** 若测试暴露真实缺陷，必须修代码。
