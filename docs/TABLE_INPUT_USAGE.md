# 牌桌快速录入 —— 使用说明（Internal Alpha）

> 本文只讲**怎么用**。策略口径与已知限制见 `ALPHA_USAGE.md`；
> 本轮的完整报告见 `reports/TABLE_INTERACTIVE_REPORT.md`。

---

## 1. 怎么开始

```powershell
cd D:\德州
node.exe --experimental-strip-types "src/app/webServer.ts"
```

然后打开 `http://127.0.0.1:5173`。

页面打开时会自动建一张 **6 人桌、Hero 在庄家位** 的空牌桌。

---

## 2. 一次性布置（开一次牌桌只做一次）

| 步骤 | 操作 | 点击次数 |
|---|---|---|
| 1 | 点「新牌桌」→ 选桌型（6 座 / 9 座）→ 选 Hero 座位 → 确认 | 3 |
| 2 | 点每个**要参与本手**的座位 → 「加入玩家」 | 每个座位 2 次 |

> **一次性成本**：6 座桌坐满约 11 次点击，9 座桌坐满约 17 次。
> 之后每一手都只需要点「下一手」，**座位不用重填**。

### 🔴 空座位**不需要**补满（Table Topology Correction）

**牌桌有几个座位（容量）与本手发几份牌（人数）是两个数字。**

- 9 座桌坐 8 人是现金局最常见的形态 —— 空着的那个座位**只是不发牌**，
  其余 8 人照常成局、照常可分析。
- 暂离同理：暂离者本手不参与（不发牌、不占盲注），**不阻断分析**。
- 唯一的要求是**本手至少有 2 个人**（少于两个人不成局），
  以及 **Hero 的座位上要有人**。

界面上方会明确写出「**9 座桌 · 本手 8 人**」，以及 Button / 小盲 / 大盲
分别在哪几个座位。本手不参与的座位在牌桌上画成**虚线变淡**，并标注
「本手不参与」。

> 从前要求「每个座位都必须有人」是因为引擎只支持满桌；
> 那个限制已经拆掉了 —— 现在空座位不再让整张牌桌无法分析。

### Button（庄家）

- **每手自动轮转**：按物理座位顺时针找下一个有人、非暂离、筹码 > 0 的座位。
- **开局可以手动指定**：本手未开始时，点那个座位 → 「设为庄家」。
  你走进牌桌时筹码牌已经在某人面前，这个按钮就是把那件事录进去。
- 牌桌上亮着「D」的就是当前 Button（不是「座位名叫庄家位的那一个」）。

## 3. 每一手（典型 9 次点击）

| 步骤 | 操作 | 点击次数 |
|---|---|---|
| 1 | 点「下一手」（清空手牌/公共牌/行动，保留座位与画像） | 1 |
| 2 | 点牌矩阵选 Hero 两张手牌（选完自动跳到公共牌） | 2 |
| 3 | 按当前行动者依次点行动按钮（弃牌/跟注/加注到…） | 4～8 |
| 4 | 轮到 Hero 时点「分析当前决策」 | 1 |
| 5 | （翻牌后）点公共牌槽位 → 点牌矩阵 | 3～5 |

**实测（`scripts/table-walkthrough.ts`）：每手中位 9 次点击，服务端总耗时约 290 ms。**
人类总耗时需要你自己点一遍才有意义 —— 脚本给的是下界。

## 4. 界面说明

### 顶部

- **桌型（6 座 / 9 座）**：这是**座位容量**，不是本手人数。
- **Hero 位置**：改 Hero 位置会旋转视图，**Hero 永远在正下方**。
  底层逻辑位置不变 —— 显示在底部 ≠ 位置是 BB。
- **本手人数条**（牌桌上方）：显示「9 座桌 · 本手 8 人」以及 Button /
  小盲 / 大盲在哪几个座位。这些数字全部来自**后端算好的拓扑**，
  前端不做任何推导。
- **下一手**：清手牌 / 公共牌 / 行动历史 / 弃牌与全下状态；保留座位、画像、动态观察、环境、Hero 位置。
- **重置本手**：录错了重来（同样保留座位与画像）。
- **撤销**：连座位绑定与画像一起恢复，不只是界面。
- **新牌桌**：弹出对话框选**桌型 + Hero 座位**，建立一张全新牌桌
  （清空所有非 Hero 座位与全部 Villain 画像/动态）。
- **清空其他玩家**：本手进行中**禁止**（会破坏底池与行动台账），会提示你先结束本手。

### 牌桌

- 每个座位显示：玩家名 / **本手角色**（含位置名）/ 剩余筹码（含本街已投入）/ 画像与动态简写 / 状态。
  - ⚠️ 座位上的角色是**本手**的角色，由 Button + 参与者每手重算。
    同一个物理座位，Button 换了，角色就换了 —— 这正是「Seat ≠ Position」。
- **当前行动者**有明显高亮，右侧同步显示「现在轮到谁」。
- 庄家位右上角有 `D` 标记（纯展示，逻辑仍来自位置定义）。
- 中央显示底池、当前注额、公共牌 5 个槽位。

### 点座位 → 座位菜单

| 菜单项 | 作用 |
|---|---|
| 快速画像 | 未知 / 很紧 / 偏紧 / 正常 / 偏松 / 很松 / 跟注站 / 主动型 / 爱诈唬 / 很少诈唬 / 疯狂型 |
| 近期观察 | 未知 / 正常 / 最近变松 / 最近变紧 / 最近很激进 / 疑似上头 / 疑似追损 |
| 暂时离座 / 重新入座 | **同一个人仍绑在这个座位上**，画像保留，只影响下一手是否发牌 |
| 更换玩家 | 生成**新身份**，画像与动态一律「未知」（绝不继承上一位玩家） |
| 清空座位 | 解除绑定。本手进行中会要求你先选「本手弃牌并离桌」或「仅标记手后离桌」 |
| 编辑筹码 | 只在**本手未开始**时可用（否则会破坏筹码守恒） |

> **弃牌请用行动按钮，不要在座位菜单里做** —— 座位菜单一旦能改行动，
> 就会出现绕过牌局引擎的第二条路径。

### 右侧

- **现在轮到你**时显示：当前底池 / 需要跟注 / 当前注额 / 最小加注到 / 有效筹码 / 我的剩余筹码。
- 行动按钮**只显示后端判定为合法的动作**。下注/加注先点动作、再点尺寸（统一写「加注到 X BB」）。
- 「分析当前决策」只在**真的能分析**时可用；不能分析时下方逐条列出原因。
- 建议区默认只显示：建议 / 尺寸 / 置信度 / 分类 / 最多 3 条原因。

### 调试面板（可折叠）

当前行动者 / 逻辑位置 / 视觉位置 / playerId 绑定 / 底池筹码 / **实际提交的
`ManualHandInput`** / 后端重放出的状态指纹 / 引擎候选与动态 Shadow。
真实测试抓 Bug 时，这些就是你要贴给开发者的东西。

## 5. 三条铁律（界面的行为都由它们决定）

```
Fold ≠ Leave Table
Seat ≠ Player
当前 Hand 的历史事实不能因为玩家离桌而被删除
```

具体表现：

- **弃牌**：只影响这一手，下一手你会看到他还在原座位。
- **离桌**：本手他的投入、行动记录、底池全都保留；下一手那个座位才空出来。
- **换人**：新玩家一律「未知」，**不会**继承上一位玩家的任何画像或动态。
- **暂离**：画像保留、当前手不变；但暂离期间**无法分析**（引擎不能把暂离玩家排除在牌局之外）。

## 6. 常见问题

**Q：为什么点了「分析当前决策」却说「信息不足」？**
多为以下之一，右侧的阻塞原因会明确写出来：

- 有 **3 名及以上**未弃牌对手（第一版只支持 1～2 名）—— 翻牌前在前位开池时很常见；
  录完其他人的弃牌、或把决策点留到翻牌后再看。
- 座位没坐满，或有人处于暂离。
- 还没轮到 Hero（要先录完前面人的行动）。

**Q：为什么加了玩家就改不了他的筹码？**
本手已经发牌了，改筹码会破坏筹码守恒。先点「重置本手」。

**Q：底池怎么不能手填？**
底池永远由后端按行动记录重算 —— 手填一个本可算出的数字只会制造「填错被阻断」的摩擦。

**Q：下一手之后筹码怎么变了？**
按上一手结束时的剩余筹码更新。⚠️ **底池未分配**（本项目不建模牌局结果），
赢家请用座位菜单的「编辑筹码」改回。
